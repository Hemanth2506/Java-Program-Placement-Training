# Java Program Placement Training

> A focused Java practice repository for strengthening programming fundamentals and problem-solving skills for placement and technical interview preparation.

## 🎯 Purpose

This repository is used to practice Java programming through progressively structured problems and core programming concepts.

## 📚 Focus Areas

- Java syntax and fundamentals
- Input and output
- Variables, data types and operators
- Conditional statements
- Loops and nested loops
- Methods and functions
- Arrays
- Strings and StringBuilder
- Basic problem-solving patterns
- Placement-oriented programming practice

## 🛠️ Tech Stack

**Language:** Java  
**Core API:** Java Standard Library  
**Practice:** Console-based programming

## ▶️ Running a Program

Make sure Java is installed and available on your PATH.

```bash
javac FileName.java
java FileName
```

For example:

```bash
javac Main.java
java Main
```

## 🧠 Learning Approach

The repository follows a practical progression:

**Learn the concept → Solve a problem → Debug → Refactor → Repeat**

The goal is to build reliable Java fundamentals before moving into more advanced data structures and algorithms.
